# Voice Cloning Architecture (`/voice-cloning`)

Framework rekayasa persona, ekstraksi leksikon, dan kloning gaya bicara/tone (*Voice Cloning Architecture*) berbasis **5 Pilar Utama** agar AI dapat mereplikasi suara, ritme, kosakata, dan pola emosi subjek secara presisi tanpa *AI-slop*.

## Struktur File
- `SKILL.md` — Dokumentasi utama skill, standar *minimum supply* kata (Level 1–3), 5 Pilar Voice Cloning, 3 Golden Rules, dan format *output* standar.

## Cara Menggunakan
1. Panggil perintah `/voice-cloning` atau `/bikin-voice-cloning`.
2. Lampirkan sampel teks/transkrip subjek (ideal **1.500 – 5.000+ kata** mencakup suasana santai, debat/friksi, hingga antusias).
3. Ekstrak hasil output berupa *Persona Summary Card*, *Dual Lexicon (50–100 vocab + blacklist)*, *Matriks Spektrum Emosi*, dan *System Prompt* siap pakai.
